# iSuite Office showcase

This is the visual showcase for five personal macOS projects: iVoz, iOrganize, Screen Bridge, iStats, and iBrain. The site preserves the original illustrated layout and links to each public source repository.

The current Mac builds are being checked before publication. The site intentionally links to source rather than unpublished release files. Screen Bridge is experimental; its performance varies by macOS version, device, and local network.

The site is static HTML and CSS. `index.html` and `index-es.html` serve desktop English and Spanish; narrow viewports redirect to `mobile.html` and `mobile-es.html`.
