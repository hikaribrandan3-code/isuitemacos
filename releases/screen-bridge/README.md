# Screen Bridge v0.1.0

## English

Turn any iPad, Android tablet, or computer into a true extended display for your Mac — zero installation required, just open a link in any browser.

**Features:**
- Real extended display via private CGVirtualDisplay (System Settings sees it as a monitor)
- Touch input relay (tap, drag, two-finger scroll, long-press right-click)
- QR code + 6-digit PIN pairing for easy setup
- Pro settings: Resolution (Retina/Standard), Image Quality (Low/Medium/High)
- mDNS discovery (`screenbridge.local`)
- WiFi or USB cable connection
- Works with iPad (iOS 13+), Android tablets (8+), any computer with a web browser

**System Requirements:**
- macOS 12.0+ (tested on macOS 15.3)
- Tablet/device with modern web browser (Safari, Chrome, Edge)

**Getting Started:**
1. Download and install Screen Bridge.app
2. Launch the app, select your tablet, hit Connect
3. Scan the QR code on your tablet, or enter the 6-digit PIN
4. Your tablet now appears as an extended display in System Settings
5. For true fullscreen on iPad: Share → Add to Home Screen

**Download:**
- `Screen Bridge_0.1.0_aarch64.dmg` — Intel/Apple Silicon Mac

## Español

Convierte cualquier iPad, tablet Android u ordenador en una pantalla extendida real para tu Mac — sin instalación, solo abre un enlace en cualquier navegador.

**Características:**
- Pantalla extendida real vía CGVirtualDisplay privada (Ajustes del Sistema la ve como monitor)
- Relé de entrada táctil (toque, arrastre, desplazamiento de dos dedos, pulsación prolongada = clic derecho)
- Emparejamiento por código QR + PIN de 6 dígitos
- Ajustes profesionales: Resolución (Retina/Estándar), Calidad de imagen (Baja/Media/Alta)
- Descubrimiento mDNS (`screenbridge.local`)
- Conexión WiFi o cable USB
- Compatible con iPad (iOS 13+), tablets Android (8+), cualquier ordenador con navegador web

**Requisitos del Sistema:**
- macOS 12.0+ (probado en macOS 15.3)
- Tablet/dispositivo con navegador web moderno (Safari, Chrome, Edge)

**Primeros Pasos:**
1. Descarga e instala Screen Bridge.app
2. Abre la app, selecciona tu tablet, pulsa Conectar
3. Escanea el código QR en tu tablet o introduce el PIN de 6 dígitos
4. Tu tablet aparece ahora como pantalla extendida en Ajustes del Sistema
5. Para pantalla completa real en iPad: Compartir → Añadir a pantalla de inicio

**Descarga:**
- `Screen Bridge_0.1.0_aarch64.dmg` — Mac Intel/Apple Silicon
